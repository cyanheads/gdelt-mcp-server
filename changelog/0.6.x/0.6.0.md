# 0.6.0 — 2026-09-24

## Added

- **`gdelt_search_themes`** — finds GKG theme identifiers in GDELT's theme lookup for the `theme:` operator, each match with its listed count and a paste-ready `operator`; token-prefix matching with one disclosed plural fallback, exact identifier ranked first, paged with `offset`/`limit` (1–100). The lookup is fetched on first use and held for the process, outside the DOC/TV rate limit. ([#40](https://github.com/cyanheads/gdelt-mcp-server/issues/40))

## Changed

- **`theme:` hints** — the `query` descriptions of `gdelt_search_articles`, `gdelt_get_coverage_timeline`, `gdelt_get_tone_distribution`, and `gdelt_get_coverage_breakdown`, and the `gdelt_search_articles` description, name `gdelt_search_themes` as the source of theme identifiers. ([#40](https://github.com/cyanheads/gdelt-mcp-server/issues/40))

## Fixed

- **`theme:` example** — `theme:DISEASE_OUTBREAK`, which GDELT's lookup does not list, is replaced by `theme:TAX_DISEASE_OUTBREAK` in the `gdelt_search_articles` description and `query` field, and in the `docs/design.md` query-syntax reference and Known Limitations. ([#40](https://github.com/cyanheads/gdelt-mcp-server/issues/40))
