# 0.6.1 — 2026-10-07

## Changed

- **`@cyanheads/mcp-ts-core` ^0.13.6 → ^0.13.13** — tool error results carry `data.requestId` and their text closes with `request <id>` (mcp-ts-core 0.13.10); stack traces and request context no longer reach error `data` (0.13.7, 0.13.8), nor does `data.rootCause` (0.13.13).
- **Argument repair** — an integer sent for a string argument, or a JSON-stringified object for an object argument, is repaired before validation (mcp-ts-core 0.13.9).
- **`gdelt_rate_limited` from a saturated request queue** — when the single in-flight slot, not the rate-limit gate, held the caller, the error reports the queued wait as `data.retryAfter` with the message "no slot opens within Ns", where it reported `retryAfter: 0` ([cyanheads/mcp-ts-core#472](https://github.com/cyanheads/mcp-ts-core/issues/472), mcp-ts-core 0.13.9).
- **Recovery hints for `invalid_date_range`, `invalid_query`, and `gdelt_unavailable`** (empty TV station catalog) now come from each tool's declared error contract instead of being forwarded at the throw site; the hints are unchanged on the wire.
- **Docker image** — production dependencies install in a `deps` stage that runs on the build platform, prunes musl-only packages from the glibc image, and moves to Bun 1.4.2 (`package.json` `packageManager` and the README badge follow). The image no longer sets `MCP_FORCE_CONSOLE_LOGGING`.
- **`server.json` npm entries** — drop the `run start:*` package arguments and set `runtimeHint: npx`; the streamable-http entry sets `MCP_TRANSPORT_TYPE=http`.
- **Ignore files** — `.gitignore` covers every `.env*` variant except `.env.example`, `.env.template`, and `.env.sample`; `.dockerignore` covers `.env*` and the MCP Registry token files; `.mcpbignore` excludes `.cache/`, `logs/`, and `docs/idea.md`; `package.json` `files` excludes `dist/*.mcpb` from the npm tarball.
- **`.env.example`** — lists `MCP_REQUEST_STATE_KEY`, `LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, and the per-signal `OTEL_EXPORTER_OTLP_*_ENDPOINT` variables.
- **Docs wording** — the package description reads "from the GDELT Project's real-time APIs"; `README.md`, `CLAUDE.md`, and `AGENTS.md` carry the framework 0.13.13 error and context text and the MCP SDK `^2.2.0` badge.
- **CodeQL workflow** — runs `actions` and `javascript-typescript` as matrix jobs, each uploading under its `/language:<language>` category.
- **Scripts and skills** — `framework-skills/` and the `scripts/` tooling are synced to the framework: `lint-packaging` gains Dockerfile build-platform and `server.json` launch-shape checks, `lint-mcp` fails on a definition that cannot be imported, `release:github` gains `--check` tag validation, and `devcheck`'s TODO and tracked-secret checks are tightened. `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts` are new, used by the Dockerfile.

- **`escapeMarkdown` linearity test** — measures per-character cost across alternating sizes and takes the fastest of 12 rounds, so scheduler pauses under a loaded suite no longer fail it.
