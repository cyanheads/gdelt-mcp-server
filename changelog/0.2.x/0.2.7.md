# 0.2.7 — 2026-08-22

## Changed

- **MCP protocol support** — Streamable HTTP now serves the modern 2026-07-28 revision alongside compatible 2025-era clients.
- **Tool input validation** — all nine tools reject undeclared root-level input fields instead of silently stripping them; callers using the advertised schemas need no changes.
- **Error result schemas** — advertised tool output schemas include the structured error envelope for clients that validate error responses.
- **Container runtime** — Docker builds use Bun 1.4.0 with production peer dependencies omitted unless this server directly imports them.
