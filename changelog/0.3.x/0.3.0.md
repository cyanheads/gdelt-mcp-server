# 0.3.0 — 2026-08-30

## Changed

- **DOC timespan inputs** now reject parseable windows shorter than 15 minutes before any upstream request; `15min` and longer supported windows remain valid ([#32](https://github.com/cyanheads/gdelt-mcp-server/issues/32)).
- **GDELT error contracts** now distinguish non-retryable `gdelt_rate_limited` responses from retryable `gdelt_unavailable` responses across all nine upstream-backed tools ([#31](https://github.com/cyanheads/gdelt-mcp-server/issues/31)).

## Fixed

- **GDELT response classification** recognizes parenthesized keyword rejections and returns invalid-query recovery instead of a serialization error ([#35](https://github.com/cyanheads/gdelt-mcp-server/issues/35)).
- **TV station-selection and request-delay documentation** now matches the server's current behavior.

## Dependencies

- `@biomejs/biome` ^2.5.9 → ^2.5.11
- `@types/node` ^26.2.0 → ^26.4.0
