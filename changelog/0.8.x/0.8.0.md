# 0.8.0 — 2026-11-01

## Added

- Added gdelt_get_tv_breakdown for station and show rankings (#69).
- **`volume_raw` on `gdelt_get_coverage_timeline`** returns matching-article counts and the unsmoothed monitored denominator `norm`, including on selected points and peaks. Smoothed values are moving averages. ([#62](https://github.com/cyanheads/gdelt-mcp-server/issues/62))
- **`combined` on `gdelt_search_tv`** pools matching and monitored clips across stations, preserving the Combined label without inventing a station ID. ([#69](https://github.com/cyanheads/gdelt-mcp-server/issues/69))
- **`gdelt-guide`** ships through npm, plugins, Docker, MCPB, and MCP Skills/resources with news/TV workflows and interpretation gates.

## Changed

- **Count paging** replaces response byte cuts: DOC timeline and tone default to 10 units (cap 400); source breakdown defaults to 10 series (cap 75); TV timeline defaults to 500 points (cap 20,000); TV context defaults to 25 terms (cap 25,000). ([#64](https://github.com/cyanheads/gdelt-mcp-server/issues/64))
- **Count clamping** accepts oversized safe positive integers without a second headroom maximum and emits `limitClamp`, one log, and one counter increment. `GDELT_CLAMP_LIMITS=false` rejects above-cap counts before upstream I/O; theme search shares this policy.
- **`smoothing`** accepts 0–30 on DOC timelines, source breakdowns, and TV timelines; widths above one disclose missing leading moving-average steps and possible peak lag. ([#68](https://github.com/cyanheads/gdelt-mcp-server/issues/68))
- **Packaging and tooling** add Agent Plugins root manifests, validate published skills, exclude development/build files from MCPB while preserving SDK runtime skill modules, classify mixed-version dependency advisories by the installed root version, and synchronize framework skills, protocol docs, and the bug-report form.

## Removed

- **BREAKING: article/clip `withheldCount`** and byte-budget continuation paths; record lists return every fetched in-window item, retaining provider-cap notices, date-window continuations, and explicit-window clipping.
- **BREAKING: TV context `totalCount`** and its unsupported upstream clip-count source; use `totalTerms` for vocabulary size, with `offset`, `nextOffset`, and `truncated` for term pages. ([#65](https://github.com/cyanheads/gdelt-mcp-server/issues/65))
- **Ten-station selector ceiling**; every requested station ID reaches upstream, with station/network/quoted-market alternatives and station-specific archive guidance. ([#67](https://github.com/cyanheads/gdelt-mcp-server/issues/67))

## Fixed

- **`referenceCount` captions** identify supplied links rather than all matching articles; exact-reference selectors retain every supplied link for the selected units. ([#63](https://github.com/cyanheads/gdelt-mcp-server/issues/63))
- **TV date resolution** reads recognized `query_details.date_resolution` before requested or inferred resolution.
- **Query recovery** names hourly-window, archive-date, conflicting-selector, and country-code faults; clearly malformed active TV timespans reject locally, and raw error/hint text passes through framework rendering once. ([#66](https://github.com/cyanheads/gdelt-mcp-server/issues/66))
- **`gdelt_rate_limited`** exposes `retryable: true` after suppressing immediate internal retries, preserves queue-shed timing and Retry-After, and advises backoff without promising recovery after five seconds. ([#70](https://github.com/cyanheads/gdelt-mcp-server/issues/70))
- **Relative windows** resolve documented long/week units for date echoes, minimum checks, and provider-cap continuations while preserving explicit-date precedence and unknown upstream syntax. ([#71](https://github.com/cyanheads/gdelt-mcp-server/issues/71))
- **Numeric rendering** preserves fractional values and denominators instead of rounding them on the text surface; Codex plugin archive guidance follows station monitoring dates.
